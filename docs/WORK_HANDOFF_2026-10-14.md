## 2. 当前架构与边界

```text
React / xterm
  → Tauri invoke / Channel
    → 同进程 Rust 业务库
      → SQLite 与本地文件
      → SSH / SFTP 目标服务器
      → 模型供应商 HTTP(S) 接口
```

- 客户端和 Rust 业务库编译为一个桌面程序，没有独立后端启动步骤、本地后端 HTTP 监听或远程 ShellPilot 后端配置。
- Rust 独立服务入口已移除；业务库仍可单独编译和测试。开发模式的 Vite 服务不属于产品后端。
- SSH 控制、模型配置、会话及历史使用 invoke；终端和模型流使用 Channel，包含关联校验与确认机制。
- SFTP 和文件内容由原生流处理，进度通过 Channel 返回；模型请求由 Rust 直接发给供应商。
- 同服务器多终端使用有界 SSH 传输池，处理单条 SSH 连接的通道限额。
- 当前 Rust Preview 版本为 0.4.0，自动更新关闭；已有安装包不能代表最新源码。

## 4. 模型配置与自动整理

在设置的模型页配置名称、供应商模型 ID、API 基础地址、相对路径、窗口与输出预留、认证和高级参数，无需通过 `.env` 配置模型。

- 配置名称可编辑，内部 ID 不变；名称、供应商模型 ID、配置版本分别保存。改名不改变密钥与历史关联。
- API Key 使用 Windows DPAPI 加密，不通过配置读取、IPC 或事件日志回显。保留、替换和清除密钥是明确操作；更换基础地址需要明确处理原密钥。
- 支持 Chat Completions 和 Responses，不能只修改路径就假定供应商支持另一套协议。
- Chat Completions 使用普通语义摘要；默认达到可用输入容量的 75% 时尝试整理，低水位为触发水位的 80%。预算是 UTF-8 启发式估算，不是精确 tokenizer。
- Responses 使用供应商输入计数。远端整理必须明确开启，供应商需要支持对应生成、输入计数和整理接口；默认关闭远端整理。
- 远端返回窗口整体保存和复用，不只保存某个加密项。窗口绑定供应商、接口、模型与凭据，不能跨配置偷偷复用。
- 最新输入、可信约束和原始日志保留。整理失败、取消、版本冲突或缩减不足时，不伪造成功，不覆盖有效旧检查点。
- AI 面板显示最近准备发送的输入占用，明确区分估算与供应商计数；点击查看窗口、预留、触发比例和记录时间。它不是累计消耗，也不包含未发送草稿或回复后的新增内容；未测量时不显示为 0%。
- 整理状态来自原生事件，成功必须有真实检查点提交；次数按检查点数量统计。失败/回退、取消、中断分别显示，重开历史可恢复。读取状态不调用模型，不回传提示或密钥。
- 用户实测发现反复摘要会丢失公开业务编号，已增加带原始用户事件出处的 `retainedUserFacts`；程序携带已收录事实到后续检查点和模型请求，防止模型重复概括时静默丢掉它们。上限 32 条、每条 512 UTF-8 字节，计入预算；旧 JSON 默认空数组，schema 不变。初次选择仍依赖模型，不保证任意细节或无限长期记忆；已丢失的旧摘要不会自动回填，升级后需重新补充待验证事实。C6 后续连续场景已完成，实际媒体能力与计数仍待 E1。
- 整理期间独立追加、尚待回复的用户补充按顺序保留在下一请求中；旧草稿不覆盖新版本。中断、用户取消和失败明确区分，原检查点/日志仍能恢复。前端仍不支持生成期间插队发送，相关竞态由内核测试覆盖。

当前数据库为 **schema 12**。schema 7 支持配置显示名称，8 支持 Responses 窗口，9 支持作用域，10 支持项目与项目聊天，11 新增按会话隔离的上下文状态快照，12 新增原生执行审批与回执；迁移保留原始日志、检查点和历史。

## 5. 项目、历史与当前界面

普通聊天不随终端页签绑定。服务器项目保存连接快照，并通过真实 SSH 身份验证主机、端口、用户名和主机密钥；不同项目、用户和聊天上下文隔离。

点击旧记录恢复原 sessionId 和原模型。重启后可重新打开同一聊天，经相同身份验证后继续；读取历史或重新绑定本身不调用模型、不创建替代聊天。断线时仍可阅读历史、讨论已有内容；这不产生任何命令执行权限。

- 项目和普通聊天从常驻侧栏进入，使用原有新建、恢复、分页和锁定逻辑。
- 保留持久项目、历史恢复及连接身份核对。
- 保留原主导航；设置分类与“终端”同级放在左侧主导航。会话、SSH、终端可以折叠，窄窗口将终端放在对话下方，组件保持挂载。

## 6. 换电脑运行

先同步两个仓库并核对上述分支/提交，确认 Cargo 能找到实际 Rust 业务库。需要兼容的 Node/npm、Rust Windows MSVC 工具链、C++ 编译工具和 WebView2；工具使用本机配置，不依赖其他电脑的绝对位置。

在客户端开发工作区运行：

```powershell
npm ci
npm run prepare:backend
npm run tauri dev
```

这些命令安装依赖、准备资源并启动桌面开发程序，不生成安装包。仅运行前端浏览器预览不能完整使用原生业务；Rust 库没有独立服务启动步骤。修改 Rust 或原生 IPC 后需要重新编译，不能只刷新前端。

Node 开发启动已加入兼容运行时选择，若仍报版本错误，检查实际使用的 Node。DPAPI 密文不能当作跨 Windows 用户/电脑可直接解密的配置，应在新电脑重新设置凭据。实际数据位置可从设置查看，改变位置不会自动迁移数据。
