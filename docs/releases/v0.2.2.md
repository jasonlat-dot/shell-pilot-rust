# ShellPilot Rust 后端 v0.2.2

本版本与 ShellPilot v0.2.2 客户端配套，以 `shellpilot_server` 库链接进桌面程序，通过 Tauri IPC 调用，无需独立服务或 Java 运行时。

## 变更

- 增加 Anthropic Messages 策略，支持文字、图片、工具调用和流式回复。
- 按协议保存、解析和回传 Chat Completions 推理字段 / Gemini 工具签名、Messages 思考块 / 签名及 Responses 原生输出；不按模型名称硬编码。
- Messages 推理强度使用 `output_config.effort`；默认省略，支持 low / medium / high / xhigh / max，具体支持范围仍以供应商为准。
- 空闲会话可切换模型，保留原会话、SSH 目标与审批策略。历史工具证据作为历史数据传入，新模型不会重放旧调用；原生签名和密文不跨绑定转发。
- 新增多模型渠道存储，原子更新公共参数、密钥和模型成员；保留稳定配置 ID，提供版本冲突和用户归属检查。
- 按日期与 Trace ID 追加 `.log` 请求日志及显式用户 / 助手正文，默认 INFO、保留 7 天，支持过期清理。
- 修复桌面调试模式中大型异步调用链导致的栈溢出。

## 迁移与兼容

数据库启动时自动依次迁移至 schema 24：22 保存供应商续接状态，23 保存模型切换边界和请求错误，24 保存渠道与成员。已有单模型配置无需批量重写，原 ID 和密钥绑定保留；旧版本已经丢弃的原生状态无法补回。

数据库、附件仍由桌面宿主管理，应用标识和默认工作区目录不变。升级前完全退出应用并备份实际工作区；未提供数据库降级，需要回退时使用升级前备份。请求日志清理不删除对话和附件。

客户端与本库需同步更新，原生代码须重新编译；只更新网页无法启用新 IPC。完整安装、签名和验收流程见兄弟客户端 [v0.2.2 升级与发布](../../../ai-ssh-terminal-client/docs/releases/v0.2.2-upgrade.md)。该文件路径按两个仓库平级检出组织。
