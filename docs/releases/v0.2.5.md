# ShellPilot Rust 后端 v0.2.5

本版本与 ShellPilot v0.2.5 客户端配套，以 `shellpilot_server` 库链接进桌面程序。新增终端目录同步、当前终端认证复用的文件访问，以及大模型与 SSH 的代理分流。

## 终端目录与身份同步

- 新增目录元数据读取及会话级集成接口，核对终端归属、连接状态和私有 nonce，复用已认证 SSH transport，不向交互终端插入 `pwd`、`ls` 等查询命令。
- 普通身份通过独立 SFTP 通道枚举目录；已接入的 sudo root Bash 通过只读元数据 worker 返回当前目录与文件信息，不重复 sudo、不保存或重放密码。
- 元数据读取限制超时、并发、条目数和响应体积，超限明确标记截断；取消、断线和身份变更释放读取通道，迟到结果不能跨身份使用。
- 目录跟随依赖当前会话的有效报告，不把二次 SSH、容器或其他服务器的提示符当作原连接身份。详见 [终端目录说明](../TERMINAL_DIRECTORY.md)。

## 文件会话复用终端认证

- 新增 `TerminalFileAccess` 与 `sftp::Manager::open_terminal`，文件会话绑定原终端 transport、身份及 revision，前端不能通过 JSON 伪造已提权身份。
- 普通身份复用原 SFTP；root 身份由已认证 Shell 经固定 FIFO 通道启动 OpenSSH `sftp-server`，用于实际上传、下载和文件操作，无需第二次认证。
- root 文件流限制数量并回收未连接通道，父 Shell 退出、身份切换、重新接入或关闭终端时撤销关联文件会话与传输；关闭文件会话不会 shutdown 共享的终端连接。
- 保留独立 SSH 登录账号和独立 sudo 文件访问方式；初始目录与允许访问的根范围分别处理。
- 身份切换和主动关闭分别返回 `SFTP_IDENTITY_CHANGED`、`SFTP_TERMINAL_CLOSED`，在目录操作、订阅及在途请求中保留原因，避免正常清理误报为资源不存在。其他终端及其文件会话互不影响。

## 网络代理与直连规则

- 大模型、模型目录和 SSH / 独立 SFTP 建连接入统一网络策略，分别保存模型与 SSH 的连接模式，支持直连、本机代理或自定义 HTTP / CONNECT、SOCKS5。
- 本机模式读取代理环境变量与当前 Windows 用户的静态系统代理；PAC 自动配置暂不执行。SOCKS5 使用代理侧 DNS，HTTP CONNECT 保留代理响应后紧随的 SSH 数据，不丢失服务器握手首包。
- 支持可选代理认证，错误提示和诊断不包含密码。代理配置整体经 Windows DPAPI 加密，IPC 只返回密码是否已保存；省略密码保留旧值，显式清除才删除。
- 两组策略分别支持 IP、精确域名、子域名通配、可选端口及 IPv6 直连白名单。HTTP / HTTPS 省略端口按 80 / 443 判断；IP 条目匹配目标 IP，不额外解析域名进行匹配。
- 白名单优先于系统及自定义代理，保存时规范化、去重并拒绝非法条目；旧配置缺少此字段时按空列表读取。本机回环地址始终直连，代理连接失败不自动改用直连。
- 运行中的模型请求保留已捕获配置，新请求读取新设置。SSH 连接池复用时检查实际代理路径和认证，更换路径后新终端不复用旧 transport；已有终端与文件传输继续使用原连接。

## 升级与验证

- 客户端与本库版本同步为 **0.2.5**。新增第 25 号迁移 `025_network_settings.sql`，幂等创建 `client_network_settings` 表保存加密配置；原有连接、模型及历史表保留。
- 需要配套重编译桌面原生程序，已有 SSH 会话需重连以加载新 Bash 集成。升级前完全退出托盘应用并备份实际工作区，回退时使用升级前完整备份。
- 目录及 sudo worker 依赖远程 Linux Bash、GNU 工具和命名管道，完整 root 文件访问还需 OpenSSH `sftp-server`；不修改远端账号、sudoers 或启动配置，不自动安装组件。
- 回环测试覆盖目录与权限隔离、文件会话撤销、HTTP CONNECT / SOCKS5、代理认证、白名单端口分流及加密保存；配套客户端覆盖模型选择、传输及设置交互。真实国外模型、SSH 网络质量、签名安装包和覆盖升级仍需发布前验收。
