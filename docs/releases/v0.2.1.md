# ShellPilot Rust 后端 v0.2.1

- 新增空闲会话的主动上下文压缩接口，复用模型配置、摘要校验和带版本检查的检查点提交。
- 与同一会话的回答、工具执行和重复压缩互斥，支持取消和工作区停止；不新增聊天轮次、不执行工具，保留原始历史。
- 支持 Chat Completions 摘要与供应商 Responses 远端整理；明确拒绝未启用的远端能力。
- 修复 Responses 在没有新增用户输入的主动整理场景中对历史窗口的处理，避免错误移除最后一条历史内容。
- 缺省模型参数统一为上下文 256000、输出预留 2048、安全预留 8192、整理阈值 75%、超时 120 秒、最大响应 1 MiB；已有显式值保持不变。
- 补充主动整理、取消、并发互斥、原始历史保留、远端能力与新缺省值的回归测试。
- 修正同一 MCP 服务的排队测试：依据实际获得执行权的调用验证串行行为，不依赖并发授权的完成顺序。

后端以 `shellpilot_server` 库嵌入 ShellPilot v0.2.1 客户端，正式数据目录迁移由客户端负责。
