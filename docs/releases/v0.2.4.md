# ShellPilot Rust 后端 v0.2.4

本版本与 ShellPilot v0.2.4 客户端配套，以 `shellpilot_server` 库链接进桌面程序，通过 Tauri IPC 调用，无需独立后端服务。

## 新增供应商

- **Kimi / Moonshot**：支持 Chat Completions 和 Messages，两协议使用 Bearer 鉴权；按协议适配思考开关、推理强度、模型目录与原生工具续聊。Temperature 沿用供应商默认值，不发送显式温度。
- **Grok / xAI**：支持 Responses 和 Chat Completions，适配推理强度、输出参数、模型目录和工具续聊。Responses 保留加密 reasoning item，使用本地输入估算并明确标记来源，不请求 xAI 未提供的 OpenAI 计数接口；可按已有开关显式使用远端上下文整理。
- **Ollama**：支持 Chat Completions、本地或远程模型目录与可选代理认证；适配 JSON / SSE 返回的 `reasoning`，在同一绑定内保留和回放。一个渠道可包含多个已部署模型，不按模型名称启用其他云端供应商的专属参数。
- 三个供应商沿用自定义基础地址、代理前缀、多模型渠道及加密密钥流程；原生思考与续接状态按供应商、协议、地址、模型及凭据隔离，不进入可见回复或诊断文本。

## 配置异常隔离

- 区分已存配置解析异常与真正数据库故障，读取列表时单独隔离损坏 JSON、未知供应商和非法参数，健康模型仍可使用。
- 新增渠道检查报告，通过 `agent/model_channel_report` 返回正常渠道与异常条目；提示不包含原始配置或密钥，读取不删除或重写异常记录。
- 渠道内任一成员异常时暂停整个渠道编辑，避免保存部分成员误删配置；同渠道其他健康模型仍可用于对话。数据库读取、锁或 SQL 故障继续返回错误。

## 模型切换与上下文

- 运行中固定使用本轮配置；配置保存或下一轮模型选择在适当的会话边界生效，工具与审批仍归原会话所有。
- 配置绑定刷新复用模型切换事务与并发保护；模型、协议、地址或凭据变化后，下一次请求使用可移植问答与工具历史，旧原生思考、签名、密文及远端检查点不跨绑定复用。
- 同一 Ollama 地址下切换 DeepSeek、Qwen 等模型保留会话、历史与审批边界，重启后仍可继续对话。
- 切换模型不再清空上下文用量，而是持久保存旧值及 `usageStale` 标记。首次新测量后替换，失败保留原统计；展示缓存不参与真实预算计算，旧数据缺少标记时兼容读取。

## SSH 服务器资源采集

- 新增 `TerminalManager::resources`，供桌面 IPC 与兼容 HTTP 接口读取 Linux / WSL 主机 CPU、内存、网卡速率、运行时长、开机时间及本地磁盘使用率。
- 复用已认证 SSH transport 的独立 exec 通道执行固定只读探针，不申请 PTY、不安装组件、不使用 sudo，也不向交互终端镜像采集命令或输出。
- CPU 与网速按远端累计计数及 uptime 差值计算；首次、重启、计数回退或长时间暂停时保持未知，不伪造零值或异常峰值。修复段间空行覆盖已解析 uptime，确保后续采样可计算 CPU 和网速。
- 每个终端独立保存缓存与上一份原始样本，限制并发采集、超时和输出体积；失败保留上次结果与原时间并标记旧数据。取消采集释放监控通道，不断开原交互终端。
- 监控对象为 SSH 原始连接主机；在 Shell 内再次登录其他服务器或进入容器不会改变监控目标。具体口径见 [SSH 资源监控说明](../TERMINAL_RESOURCES.md)。

## 升级与兼容

本版本数据库仍为 **schema 24**，不新增迁移。已有模型、加密密钥、历史、附件与工具证据继续保留；旧兼容渠道不会按域名或模型名称自动转换供应商。

客户端与本库版本需同步为 **0.2.4**，并重新编译桌面程序。升级前从托盘完全退出并备份实际工作区；新增供应商不保证可由旧版解析，需要回退时使用升级前完整备份。配置异常隔离仅在新版生效，不会改变已安装旧版的读取逻辑。
