# ShellPilot Rust 后端 v0.2.3

本版本与 ShellPilot v0.2.3 客户端配套，以 `shellpilot_server` 库链接进桌面程序，通过 Tauri IPC 调用，无需独立后端服务。

## 供应商与协议

- 新增 Google Gemini GenerateContent 原生协议，支持文字、图片、流式回复、工具调用、原生思考签名续接和本地语义摘要。
- 新增 DeepSeek、GLM / 智谱和 Qwen / 通义千问独立供应商策略，复用 Chat Completions 与 Messages 协议适配，分别处理思考模式、推理强度、温度和输出参数。
- 按供应商规则保留并回传实际返回的推理内容、签名和工具调用状态；通用 Anthropic 的签名校验保持原有要求。续接状态按供应商、协议、端点、模型及凭据隔离，不进入可见回复或诊断日志。
- Qwen 完整回复、工具规划和摘要入口统一通过 SSE 收集结果，保留取消、超时、大小及结束帧校验；不因断流或参数不支持自动重试、降档或重复执行工具。
- DeepSeek、GLM、Qwen 独立入口本次仅开放 Chat Completions 和 Messages；Qwen 不包含 DashScope 原生生成协议。模型及代理实际支持的能力仍需独立验证。

## 模型目录与渠道

- 增加只读模型目录查询，支持 OpenAI / Responses、Anthropic、Google 及新增供应商；复用已保存的加密凭据，不保存配置草稿或回显 API Key。
- Google 按原生分页读取并过滤支持 generateContent 的模型；DeepSeek 与 Qwen 通过供应商策略适配目录地址、鉴权及返回结构，保留自定义代理前缀。
- GLM 按配置端点查询 models，不探测其他地址或伪造列表；上游未提供目录时返回明确错误，客户端可继续手动维护模型 ID。
- 查询保留取消、30 秒超时、20 页、8 MiB 和 10000 条边界，异常分页或超限不作为部分成功返回。
- 查询过程接入独立 Trace 日志，记录请求地址、状态和解析错误，排除密钥、响应原文与分页游标。
- 渠道按创建先后稳定返回，编辑、改名、转换渠道或移除首个模型不改变原有顺序；无需新增创建时间字段或迁移。

## 工具输出回读

- `read_tool_output` 默认读取 4096 字节（4 KiB），单次最多 16384 字节（16 KiB）。省略 limit 时由宿主补齐，超限正整数封顶；零、负数、小数、null 和字符串仍作为非法参数拒绝。
- 主任务与子任务共用参数归一化和结果额度。按当前用户、会话和任务校验输出归属，使用 nextOffset / eof 分页，不重新执行 SSH 命令。
- 回读不占工具执行次数，后续模型请求仍占轮数，执行权限、上下文和取消边界保持原有规则。
- 回读结果单独使用 132 KiB 有界封装额度，容纳原文、精确 bytesHex 和 JSON 转义；ToolResult 历史事件上限为 192 KiB。普通工具默认结果仍为 8 KiB，其他历史事件仍为 64 KiB。
- 首次命令摘要、原始输出捕获与存储上限不变，界面完整输出仍使用独立分页读取。

## 升级与兼容

本版本数据库仍为 schema 24，不新增迁移。已有模型、加密密钥、会话和工具证据保留；旧兼容渠道不会按名称或域名自动改为新增供应商。需要使用独立策略时，在客户端编辑渠道并选择供应商。

客户端与本库版本需同步为 0.2.3，并重新编译桌面程序。升级前完全退出托盘进程并备份实际工作区；需要回退时使用升级前完整备份，不以 schema 未变化推断旧程序能够处理所有新增供应商和输出记录。
